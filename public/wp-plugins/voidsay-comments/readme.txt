# VoidSay Comments — WordPress Plugin

**Universal, Ad-Free Commenting for WordPress**

Replace your default WordPress comments with VoidSay — a modern, privacy-first commenting platform that works on any URL.

## Features

- **🔌 Zero Configuration**: Just add `[voidsay]` anywhere in your post.
- **🚫 Ad-Free Forever**: No ads, no tracking, no dark patterns.
- **🎨 Modern Design**: Dark theme, Markdown support, rich media embeds.
- **📱 Mobile-First**: Responsive iframe embed, works on any screen.
- **🔍 SEO-Friendly**: Comments are indexed by search engines.
- **🆓 Free Tier**: Unlimited comments, unlimited threads.

## Installation

### Via WordPress Admin (Recommended)
1. Download the plugin ZIP from [voidsay.com/wp-plugins/voidsay-comments.zip](https://voidsay.com/wp-plugins/voidsay-comments.zip)
2. Go to **Plugins → Add New → Upload Plugin**
3. Choose the ZIP file and click **Install Now**
4. Activate the plugin

### Manual Installation
1. Upload the `voidsay-comments` folder to `/wp-content/plugins/`
2. Activate the plugin through the **Plugins** menu

## Usage

### Shortcode
```
[voidsay]
```
Optionally override URL:
```
[voidsay url="https://example.com/my-page" width="100%" height="500px"]
```

### Gutenberg Block
1. Search for "VoidSay" in the block inserter
2. Add the **VoidSay Comments** block
3. Optionally set a custom URL in the block settings
